8Como copiar o HTML de cada email

No dashboard, passe o mouse sobre qualquer card de email. Aparece um botão "📋 Copiar" no canto superior direito. Clica:

  1. O navegador faz fetch do HTML completo do email
  2. Copia pro clipboard automaticamente
  3. Botão muda pra "✓ Copiado!" por 1.8s confirmando sucesso

No MailerLite, vá em Edit content → Source/HTML mode → cola (Ctrl+V) → salva. Sempre faz "Send test email" antes de finalizar.

Se o botão der erro

Pode acontecer se o navegador bloquear clipboard API (ex: HTTP em vez de HTTPS). Fallback manual:

  1. Clica no card normal (abre o email em nova aba)
  2. Botão direito → "Exibir código-fonte" (Ctrl+U)
  3. Ctrl+A → Ctrl+C → cola no MailerLite
